## 本轮可以使用的功能

`/contribute` 接受多文件及普通 ZIP，支持 CIF/POSCAR 结构、CSV/TXT/XY 数值曲线、物性表，以及不解析的仪器原文件和图像附件。选择文件只读取本地数据。点击保存后，原始字节和草稿元数据写入同源浏览器的 IndexedDB；`/workspace` 按保存批次显示和继续编辑。

本地工作台没有登录、用户隔离或服务器访问控制。这里的私有选项记录未来提交意愿；同一浏览器配置中访问此网站的人仍可打开本地草稿。刷新可恢复已保存的草稿，未保存的编辑不会自动存储。JSON 导出包含原始文件和联系信息，应作为本地备份妥善保存；清除浏览器数据会删除本地副本。

当前限制：100 个文件、300 条记录、每个原文件 10 MiB、解包后总计 50 MiB；普通 ZIP 压缩文件不超过 64 MiB。支持 stored/deflate、ASCII/UTF-8 路径；加密、分卷、ZIP64、符号链接和不安全路径拒绝导入。不支持原生解压的浏览器可先解压再选择文件。当前曲线预览上限为 10,000 行、64 列。物性表支持单行测量值，单点以数值卡显示；拉曼和 XRD 曲线仍至少需要两个有效数据点。

结构检查仅用于发现基本格式问题，不能确认晶体学正确性、成分一致性、相稳定性或所有权。曲线按文件中真实数值和顺序绘制，不平滑、拟合、归一化或推断缺失值。原始字节保留并计算 SHA-256，导入 v2 JSON 时重新校验。此前 v1 单结构草稿可迁移为新的私有批次，重新确认权限；旧格式只保留解码文本，无法恢复原文件中未保留的编码字节。

## 批量关联方式

文件选择器可以同时选择多个文件；保留文件夹结构的批次使用 ZIP。在压缩包内提供一个 `manifest.csv`，或先添加原文件再单独导入清单。CSV 模板只包含表头，不插入科学示例数据。

清单至少包含 record_id、file、origin、data_type 四列，来源类型不能留空。每一行定义一条记录。同一个数值文件可重复引用，指定不同 Y 列、压力和温度，形成多条独立曲线；原文件只保存一份。用完整相对路径匹配，只有唯一文件名才允许简写；歧义、缺失文件、重复记录 ID 或未映射原文件都会明确报错，不按文件名猜测压力和样品。

| 字段                                           | 含义                                                      |
| ---------------------------------------------- | --------------------------------------------------------- |
| `record_id`, `file`                            | 批次内唯一记录 ID、原文件相对路径                         |
| `origin`                                       | `experimental` / `theoretical`                            |
| `data_type`                                    | `structure` / `raman` / `xrd` / `property` / `attachment` |
| `sample_id`, `formula`                         | 提供者样品标签、声明的成分                                |
| `pressure_gpa`, `temperature_k`                | 真实记录条件；0 GPa 是有效值，空值不等于 0                |
| `phase_label`                                  | 可选的提供者相指认，不能自动变为已验证相 ID               |
| `structure_record_id`                          | 可选的同批次结构关联，须明确选择且样品标签一致            |
| `processing`                                   | `raw` / `processed`，保留原始与处理后数据的区分           |
| `x_quantity`, `x_unit`, `y_quantity`, `y_unit` | 坐标物理量与单位，由提供者确认                            |
| `x_column`, `y_column`                         | 唯一列名或从 0 起的列索引；不能使用同一列作为 X/Y         |
| `method`, `source`, `notes`                    | 实际实验/计算方法、来源归属及可选科学备注                 |

实验记录要求明确温度；理论记录的温度可留空，但不得自动写为 0 K。拉曼与 XRD 默认单位可修改，不能把所有 XRD 文件都当成相同的 2θ/波长数据。仪器参数、波长、几何条件、误差和处理步骤写入方法与科学备注，后续再按确认的领域模型拆分字段。2D 衍射图及专有格式暂时作为附件保存，不声明已转换成一维谱图。

关系采用 **批次 → 文件 / 记录 → 样品、条件、可选结构关联**。同成分或同样品标签不代表同一相；不同压力、实验与理论原点分别保留。谱图不具备可靠结构关联时可以独立存在，不强制建立材料或相身份。

## 公开与计算权限

- 默认 `private`，未来仅所有者和授权审核人员可访问；公共搜索、预览、聚合统计、原文件下载、日志和事件流均须排除私有数据。
- 用户主动选择 `public-after-review` 后，逐条审核通过的贡献记录才具备公开资格。选择公开意愿不等于当前公开，也不等于审核通过。
- `computationRequested` 独立于可见范围。私有批次可以授权计算，结果继承私有范围；计算完成、质检通过或入库均不能自动扩大访问范围。
- 切换可见范围后须重新确认贡献权限。实际提交时需服务端验证政策版本、权限及数据许可，不能把前端勾选当作访问控制。
- 未来修改已提交批次的范围需独立、可审计操作，并明确影响原记录及衍生结果。服务端 ACL 是最终依据。

公开的理论贡献在平台标准计算通过前显示红色星标，同时使用文字 **Community contribution · Standardization pending**；红色本身不能承担状态解释。标准化失败或待补资料必须显示具体状态，不能仅隐藏星标。实验数据标注实验来源、测量条件与审核状态，不因关联了计算结果而变为理论数据。

原始贡献与平台标准化结果采用不同记录 ID，通过输入/输出关联并列保存；计算结果不得覆盖上传记录。公共展示仍需后续材料详情与检索服务支持，本轮仅有说明和状态接口，没有虚构已公开记录。

## 状态与进度

每条记录分别保存审核、公开、计算、质量检查、入库状态，批次汇总各状态计数。一个批次可以部分通过、部分待补资料或不适用计算。

| 维度 | 示例状态                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------------- |
| 审核 | not-submitted / pending / needs-information / approved / rejected                                        |
| 公开 | private / pending-publication / public / withdrawn                                                       |
| 计算 | not-requested / not-applicable / pending-eligibility / queued / running / failed / cancelled / completed |
| 质量 | not-started / pending / needs-review / passed / failed                                                   |
| 入库 | not-ingested / pending / ingested / withdrawn                                                            |

目前本地草稿统一显示未提交、未公开、计算未开始、未入库；不会出现假的审核或 0–100% 动画。

工作流百分比必须标明口径。最终计划确定后，可显示“已成功完成的必需步骤 / 必需步骤总数”，这是步骤完成比例，不是剩余耗时预测。计划不确定、无必需步骤、状态不一致或全部步骤完成但作业未确认完成时，百分比不可用。失败流程不得显示成功的 100%。批次可以另显示“计算完成记录数 / 确认需计算的记录数”，不能把不适用谱图也算入分母。

若已有脚本能提供可靠的单步骤数值，可返回百分比和 `basis`；没有可靠指标时只显示流程名、状态、最近事件和时间。SCF 迭代次数不能直接冒充任务总进度。重试保留 attempt 和历史事件，不能覆盖失败记录。

## VASP 脚本对接边界

使用现有脚本的服务端适配器，不在浏览器执行计算，也不执行用户上传的任意程序。审核通过、贡献授权和计算资格均满足后，服务端建立计算任务，固定输入结构、真实请求压力和平台协议 ID/版本。谱图没有可计算结构时标为不适用或等待结构资料，不自动产生晶体结构。

页面读取服务端实际步骤图，支持分支、依赖、重试、调度队列 ID、当前步骤、日志摘要和输出记录。几何优化、静态计算或其他流程是否存在、先后顺序和数值参数，需等待已有脚本与平台协议确认，页面不硬编码一套未经确认的科学流程。

任务完成后仍须质量检查和入库确认；completed 不等于 quality passed，也不等于 ingested。平台规范、VASP/势文件授权、资源调度和失败重试策略待实际后端设计时确认。

## 预留 HTTP 接口

类型位于 `lib/materials/contribution-contract.ts`。下表是拟议接口，不是已经运行的服务；当前页面不调用它们。

| 接口                                              | 职责                                                                                 |
| ------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `POST /contribution-upload-sessions`              | 登录后创建上传会话，声明文件路径/大小/原始 SHA-256；返回短时文件上传地址与服务端限制 |
| `POST /contribution-upload-sessions/:id/finalize` | 服务端重新校验文件完整性、权限和内容；返回可提交的文件 ID，未完成文件不得引用        |
| `POST /contribution-batches`                      | 一次提交批次元数据、文件关联、记录、明确可见意愿和独立计算授权                       |
| `GET /me/contribution-batches?cursor=…`           | 仅当前所有者的批次摘要和分页                                                         |
| `GET /me/contribution-batches/:id`                | 记录级状态、文件、真实运行计划及最后事件序号                                         |
| `GET /me/contribution-batches/:id/events?after=…` | SSE 增量状态通知；断线按单调事件序号恢复，轮询详情作为降级方式                       |
| `GET /me/contribution-batches/:id/files/:fileId`  | ACL 检查后的短时私有下载地址，不生成永久公共原文件 URL                               |

写入接口须支持同一用户范围内的 `Idempotency-Key`，最终提交事务化；超时重试不能建立重复批次或重复作业。文件上传可由实际存储提供可续传协议，浏览器端限制仅是本地预检，服务端必须独立执行限额、解包、哈希、格式、权限和来源检查。

身份来自认证会话，不接受前端任意 `ownerId`。批次、文件、事件、日志和输出均须验证所有权；审核操作放在独立的审核权限接口。公共索引只消费同时满足公开意愿和审核条件的记录，私有数据不得因前端过滤遗漏而泄露。

响应错误采用结构化 `code/message/requestId/issues`，记录级错误定位到记录与字段。客户端仅应用更新的事件序号；重连先取快照再追增量，避免旧响应覆盖新状态。工作流状态由服务端更新，前端不接受“模拟开始/完成”操作。

下一次接入需要实际认证与存储方案、已确认的审核/许可政策，以及现有 VASP 脚本的输入输出和事件协议。本轮没有执行或请求这些外部操作。

## 账户与署名（v8）

贡献编辑与我的贡献需要登录。个人资料中的机构、课题组和职业阶段仅在点击 Apply my profile 时复制为批次署名快照；之后仍可手动修改。资料改变不会修改已保存批次。浏览器草稿按当前账号区分；旧草稿保留为未归属草稿，通过用户确认复制并重置授权。正式服务由会话确定 ownerId，不能相信署名或客户端传入的所有者。详见 [认证接入指南](AUTHENTICATION.md)。
